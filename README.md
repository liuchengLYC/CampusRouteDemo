# CampusRouteDemo

CampusRouteDemo 是一個以台大校園為範圍的互動式導覽網站。網站目前包含「路線導覽」與「休憩點與危險點」兩個頁面，使用者可以查看預設校園路線、取得步行導航步驟，也可以切換到校園地圖查看不同地點的標記與介紹。

## 專案功能

### 路線導覽

- 顯示台大校園地圖
- 提供多條預設校園路線
- 在地圖上標示路線節點
- 載入路線後顯示預覽線
- 透過 OSRM Route API 取得實際步行路徑
- 顯示路線總距離、預估時間與導航步驟數
- 顯示完整導航步驟列表
- 支援「上一步」與「下一步」切換目前導航步驟
- 在地圖上標示目前步驟的起點與終點
- 支援手動路線模式，適合處理 API 路徑不理想的情況

### 休憩點與危險點

- 提供第二個校園地圖頁面
- 在地圖上標示校園地點
- 顯示地點圖例
- 點擊地圖標記可查看地點名稱
- 地點資料集中放在 `src/data.js` 中，方便後續新增或修改

### 定位功能

- 使用瀏覽器定位功能顯示使用者目前位置
- 若使用者距離路線起點較遠，會加入前往起點的導引線段
- 接近目前步驟終點時，可以自動切換到下一個導航步驟
- 若瀏覽器不支援定位或使用者未開啟定位，仍可手動瀏覽導航步驟

## 如何使用

1. 開啟網站首頁。
2. 在「路線導覽」頁面選擇想查看的路線。
3. 點擊「載入路線」查看路線節點與預覽線。
4. 點擊「顯示路線」產生實際步行路徑與導航步驟。
5. 使用「上一步」與「下一步」查看不同導航步驟。
6. 切換到「休憩點與危險點」頁面，可以查看校園地點標記與圖例。

## 如何新增路線

路線資料放在 `src/data.js` 的 `ROUTES` 物件中。新增路線時，加入一組新的 key，並設定 `name` 與 `points`。每條路線至少需要兩個座標點。

```javascript
export const ROUTES = {
  example_route: {
    name: "起點 → 中繼點 → 終點",
    points: [
      { name: "起點", lat: 25.00000, lng: 121.00000 },
      { name: "中繼點", lat: 25.00050, lng: 121.00050 },
      { name: "終點", lat: 25.00100, lng: 121.00100 }
    ]
  }
};
```

如果希望路線完全依照自己設定的節點連線，而不是交給 OSRM API 自動產生路徑，可以在路線資料中加入 `useManualPath: true`。

```javascript
export const ROUTES = {
  manual_route: {
    name: "手動路線範例",
    useManualPath: true,
    points: [
      { name: "第 1 點", lat: 25.00000, lng: 121.00000 },
      { name: "第 2 點", lat: 25.00050, lng: 121.00050 },
      { name: "第 3 點", lat: 25.00100, lng: 121.00100 }
    ]
  }
};
```

## 如何新增校園地點

校園地點資料放在 `src/data.js` 的 `CAMPUS_POINTS` 陣列中。新增地點時，加入名稱、座標與介紹文字即可。

```javascript
export const CAMPUS_POINTS = [
  {
    name: "地點名稱",
    lat: 25.00000,
    lng: 121.00000,
    description: "這裡可以放地點介紹"
  }
];
```

## 注意事項

- 本專案目前使用公開 OSRM API，若請求過於頻繁可能會受到限制。
- OSRM 產生的路線會依照 OpenStreetMap 資料計算，實際結果可能與校園內真實可走路徑不同。
- 若 OSRM 產生的路線不理想，可以增加中繼點，或改用 `useManualPath: true` 的手動路線模式。
- 定位功能需要使用者允許瀏覽器定位權限；若未允許定位，仍可使用手動導航步驟。
- 本網站目前適合作為課程展示或原型測試，尚未針對大量使用者或正式部署進行最佳化。
